# Network Topologies

Network topology refers to the physical or logical arrangement of nodes (computers, servers, etc.) and connections in a network.

## Types of Network Topologies

### 1. Bus Topology

```
    ════════════════════════════════════════  ← Backbone Cable
    │          │          │          │
   💻         💻         💻         💻
  Device A   Device B   Device C   Device D

  ⬅─── Data travels in both directions ───➡

  💡 If the backbone breaks here ✂️, the entire
     network on the other side goes down.
```

- All devices connected to a **single central cable** (backbone/trunk).
- Data sent by one device travels along the cable — **all devices receive it**, only the intended recipient processes it.
- Terminators at both ends absorb signals to prevent **signal bounce**.
- **Advantages:** Simple, low cost, easy to expand
- **Disadvantages:** Single point of failure, limited cable length, collision issues
- **Use Case:** Small networks, LANs

---

### 2. Star Topology

```
        💻 Device A
         \
          \
  💻 ──── 🔀 Switch/Hub ──── 💻
 Device B     (Center)       Device D
          /
         /
        💻 Device C

  💡 Every device has a dedicated link to the center.
     If Device C fails, others are unaffected.
     If the Switch fails ❌, entire network goes down.
```

- All devices connect to a **central hub or switch**.
- **Advantages:** Easy to manage, fault isolation, good performance, scalable
- **Disadvantages:** Central point of failure, higher cost
- **Use Case:** Most modern networks, enterprise LANs

---

### 3. Ring Topology

```
          💻 Device A
         ╱            ╲
        ↓              ↑
  💻 Device D      💻 Device B
        ↑              ↓
         ╲            ╱
          💻 Device C

  Data flows ───➡ in ONE direction (unidirectional)

  ════════════════════════════════════════
  Dual Ring (FDDI) — data flows in BOTH directions:

          💻 Device A
        ╱ ↕ ╲
  💻 Device D ↔ 💻 Device B
        ╲ ↕ ╱
          💻 Device C

  💡 If one ring breaks, the other ring takes over.
```

- Devices connected in a **circular loop** — each device has exactly 2 neighbors.
- Data passes through each device until it reaches the destination.
- **Token Ring**: only the device holding the "token" can transmit (prevents collisions).
- **Advantages:** Fair bandwidth distribution, good performance with heavy traffic
- **Disadvantages:** Single point of failure, difficult to troubleshoot, slow data transmission
- **Use Case:** Token Ring networks, FDDI

---

### 4. Mesh Topology

```
  Full Mesh — Every device connected to every other device:

      💻 A ──────────── 💻 B
      │ ╲              ╱ │
      │   ╲          ╱   │
      │     ╲      ╱     │
      │       ╲  ╱       │
      │        ╳         │
      │       ╱ ╲        │
      │     ╱     ╲      │
      │   ╱         ╲    │
      │ ╱             ╲  │
      💻 D ──────────── 💻 C

  Connections = n(n-1)/2 → 4 devices = 6 connections

  ════════════════════════════════════════

  Partial Mesh — Only some devices interconnected:

      💻 A ──────────── 💻 B
                       ╱ │
                     ╱   │
                   ╱     │
                 ╱       │
      💻 D ──────────── 💻 C

  💡 Full mesh is expensive but ultra-reliable.
     Partial mesh balances cost and redundancy.
```

- Every device connected to every other device.
- **Types:** Full mesh (every connection), Partial mesh (selective connections)
- **Advantages:** Redundancy, high reliability, fault tolerance
- **Disadvantages:** Expensive, complex, difficult to manage
- **Use Case:** Critical networks, military applications, backup systems

---

### 5. Tree Topology

```
                    🖥️ Root Server
                   ╱       │       ╲
                 ╱         │         ╲
          🔀 Switch A   🔀 Switch B   🔀 Switch C
          ╱    ╲           │          ╱    ╲
        ╱        ╲         │        ╱        ╲
      💻 A1    💻 A2     💻 B1   💻 C1    💻 C2
                                    │
                                 🔀 Sub-Switch
                                 ╱        ╲
                               💻 C3    💻 C4

  💡 Hierarchical structure — like an org chart.
     Root failure = entire subtree goes down.
```

- Hierarchical arrangement combining **bus and star** topologies.
- Parent-child relationship between nodes.
- **Advantages:** Scalable, organized, easy to manage
- **Disadvantages:** Complex, central node failure affects subnodes
- **Use Case:** Large corporate networks, hierarchical structures

---

### 6. Hybrid Topology

```
  Example: Star + Ring + Bus combined

   ┌── Star Network ──┐     ┌── Ring Network ──┐
   │   💻     💻      │     │  💻 → 💻 → 💻   │
   │    ╲   ╱         │     │  ↑           ↓   │
   │    🔀 Switch     │     │  💻 ← 💻 ← 💻   │
   │    ╱   ╲         │     │                   │
   │   💻     💻      │     └────────┬──────────┘
   └────────┬─────────┘              │
            │                        │
            └──── 🔀 Core Router ────┘
                       │
              ┌────────┴─────────┐
              │   Bus Network    │
              │  ═══╤════╤═══   │
              │    💻   💻      │
              └──────────────────┘

  💡 Take the best of each topology.
     Most real-world networks are hybrid.
```

- Combination of **two or more** basic topologies.
- **Advantages:** Flexible, scalable, combines benefits of multiple topologies
- **Disadvantages:** Complex design and management
- **Use Case:** Large enterprise networks

---

## Logical vs Physical Topology

- **Physical Topology:** The actual physical layout of cables and devices
- **Logical Topology:** The logical arrangement of how data flows through the network (e.g., Ethernet uses logical bus topology over physical star)

```
  Physical = Star               Logical = Bus
  (how it's wired)              (how data flows)

      💻                        💻──💻──💻──💻
     ╱ │ ╲                     All devices on same
  💻 🔀  💻                    broadcast domain
     ╲ │ ╱
      💻

  💡 Modern Ethernet: physically a star (via switch),
     but logically behaves like a bus (broadcast frames).
```

## 📊 Quick Comparison

| Topology | Diagram Shape | Fault Tolerance | Cost | Scalability | Real-World Use |
|----------|--------------|-----------------|------|-------------|----------------|
| **Bus** | Straight line | ❌ Low | 💰 Cheapest | Limited | Legacy LANs |
| **Star** | Spokes from center | ⚠️ Medium | 💰💰 | Easy | Home/Office (most common) |
| **Ring** | Circle | ❌ Low (⚠️ Dual ring) | 💰💰 | Moderate | FDDI, Token Ring |
| **Mesh** | Web/Grid | ✅ Highest | 💰💰💰 | Hard | Data centers, military |
| **Tree** | Hierarchy | ⚠️ Medium | 💰💰 | Good | Enterprise, campus |
| **Hybrid** | Mixed | Varies | 💰💰💰 | Best | Real-world networks |
