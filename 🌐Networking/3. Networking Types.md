## 🌐 Network Types Overview

> Networks are classified by **size, range, and purpose**. From connecting devices in your room to connecting continents — each type serves a different scale.

```
You ← → Your Room ← → Your Building ← → Your City ← → Your Country ← → The World

PAN       LAN            CAN/MAN           MAN           WAN            Internet (GAN)
```

---

## 1️⃣ PAN — Personal Area Network

> Connects devices within **a person's reach** (~1–10 meters).

- Shortest range network.
- Usually wireless (**Bluetooth, NFC, Infrared**).
- Examples:
  - Phone ↔ Bluetooth earbuds
  - Smartwatch ↔ Phone
  - Laptop ↔ Wireless mouse/keyboard
  - Phone ↔ NFC payment terminal

```
📱 Phone ──Bluetooth── 🎧 AirPods
   │
   └──Bluetooth── ⌚ Smartwatch
```

| Feature | Detail |
|---------|--------|
| Range | ~1–10 meters |
| Technology | Bluetooth, NFC, Infrared, USB |
| Speed | Low–Medium |
| Ownership | Individual/Personal |

---

## 2️⃣ LAN — Local Area Network

> Connects devices within a **single building or small area** (home, office, school).

- The **most common** network type you interact with daily.
- Uses **Ethernet (wired)** or **Wi-Fi (wireless — WLAN)**.
- Managed by a **switch** (Layer 2) and often a **router** for internet access.
- High speed, low latency, privately owned.

```
🏠 Home LAN

Laptop ──Wi-Fi──┐
Phone  ──Wi-Fi──┤── Router ──── ISP ──── Internet
Desktop──Ethernet┘     │
                    Switch
                    ┌──┴──┐
                Printer  NAS
```

| Feature | Detail |
|---------|--------|
| Range | ~100m – 1km |
| Technology | Ethernet (802.3), Wi-Fi (802.11) |
| Speed | 100 Mbps – 10 Gbps |
| Ownership | Private (home, office, school) |
| Devices | Switch, Router, Access Point |

### 📶 WLAN — Wireless LAN

- A LAN that uses **Wi-Fi** instead of cables.
- Same scope as LAN, just wireless.
- Uses **Access Points (APs)** to connect devices.

---

## 3️⃣ CAN — Campus Area Network

> Connects multiple **LANs within a campus** (university, corporate campus, hospital).

- Larger than a LAN but smaller than a MAN.
- Multiple buildings connected via **fiber optic cables** or **wireless bridges**.
- Owned and managed by a **single organization**.

```
🏫 University Campus

Building A (LAN) ──Fiber── Core Switch ──Fiber── Building B (LAN)
                              │
Building C (LAN) ──Fiber──────┘
                              │
                           Router ──── Internet
```

| Feature | Detail |
|---------|--------|
| Range | ~1–5 km |
| Technology | Fiber optics, Ethernet, Wireless bridges |
| Speed | 1–10 Gbps |
| Ownership | Single organization |

---

## 4️⃣ MAN — Metropolitan Area Network

> Connects multiple **LANs/CANs across a city or metropolitan area**.

- Larger than a CAN, covers an **entire city**.
- Typically owned by **ISPs, telecom companies, or city governments**.
- Examples: city-wide Wi-Fi, cable TV networks, ISP backbone within a city.

```
🏙️ City-wide MAN

Office LAN (Downtown) ──┐
University CAN ──────────┤── ISP Metro Network ──── Internet
Hospital LAN ────────────┘        │
                          City Library LAN
```

| Feature | Detail |
|---------|--------|
| Range | ~5–50 km (city-wide) |
| Technology | Fiber, WiMAX, Metro Ethernet |
| Speed | 100 Mbps – 10 Gbps |
| Ownership | ISP / Telecom / City government |

---

## 5️⃣ WAN — Wide Area Network / Internet

> Connects networks across **large geographical areas** — cities, countries, continents.

- The **Internet is the largest WAN**.
- Uses **leased lines, MPLS, VPN, satellite, undersea cables**.
- Not owned by a single entity — relies on **ISPs and telecom providers**.
- Higher latency than LAN due to distance.

```
🌍 WAN

Mumbai Office (LAN) ───VPN/MPLS──── New York Office (LAN)
        │                                    │
    ISP India ──Undersea Cable──── ISP USA
```

| Feature | Detail |
|---------|--------|
| Range | Unlimited (global) |
| Technology | MPLS, Leased Lines, VPN, Satellite, Fiber |
| Speed | Varies (1 Mbps – 100+ Gbps) |
| Latency | Higher than LAN |
| Ownership | ISPs, Telecom providers |

### 🔐 VPN — Virtual Private Network

- Creates a **secure encrypted tunnel** over a public WAN (internet).
- Used to connect remote offices or remote employees to a company's private network.
- Operates at Layer 3 (IPsec) or Layer 4 (SSL/TLS VPN).

```
Remote Employee                           Company Office
  💻 ──── Encrypted VPN Tunnel ──── 🏢 Private Network
         (over public internet)
```

---

## 6️⃣ SAN — Storage Area Network

> A **dedicated high-speed network** for connecting storage devices to servers.

- Not a general-purpose network — specifically for **block-level storage access**.
- Used in **data centers** and **enterprise environments**.
- Makes storage devices (disk arrays, tape libraries) appear as **locally attached** to servers.
- Protocols: **Fibre Channel (FC), iSCSI, FCoE**.

```
🏢 Data Center SAN

Server 1 ──┐
Server 2 ──┤── SAN Switch ──┤── Storage Array (SSD/HDD)
Server 3 ──┘                └── Tape Library (Backup)
```

| Feature | Detail |
|---------|--------|
| Purpose | Storage access only |
| Technology | Fibre Channel, iSCSI |
| Speed | 8–32 Gbps (FC), 10–100 Gbps (iSCSI) |
| Location | Data centers |

---

## 7️⃣ SD-WAN — Software-Defined WAN

> A **software-managed** approach to WANs that simplifies branch office connectivity.

- Separates the **control plane** (routing decisions) from the **data plane** (forwarding).
- Intelligently routes traffic over **multiple links** (MPLS, broadband, LTE).
- Reduces cost by using **cheap internet links** instead of expensive MPLS everywhere.
- Central management via a **cloud controller**.

```
Branch Office
  💻 ── SD-WAN Edge ──┬── MPLS (critical apps)
                      ├── Broadband (general traffic)
                      └── LTE (backup)
                      
All controlled by a central SD-WAN Controller (cloud)
```

## 📊 Comparison Table

| Type | Range | Speed | Ownership | Example |
|------|-------|-------|-----------|---------|
| **PAN** | ~1–10m | Low–Med | Personal | Bluetooth earbuds |
| **LAN** | ~100m–1km | High (1–10 Gbps) | Private | Home/Office Wi-Fi |
| **WLAN** | ~100m | High | Private | Wi-Fi network |
| **CAN** | ~1–5km | High (1–10 Gbps) | Organization | University campus |
| **MAN** | ~5–50km | High | ISP/City | City metro network |
| **WAN** | Unlimited | Varies | ISP/Telecom | Internet, MPLS links |
| **SAN** | Data center | Very High | Enterprise | Fibre Channel storage |
| **SD-WAN** | WAN scale | Varies | Organization | Branch office links |

## 🔄 How They Nest Together

```
┌──────────────────────────────────────────────┐
│                  WAN / Internet               │
│  ┌──────────────────────────────────────┐    │
│  │              MAN (City)              │    │
│  │  ┌──────────────────────────────┐    │    │
│  │  │         CAN (Campus)         │    │    │
│  │  │  ┌──────────────────────┐    │    │    │
│  │  │  │     LAN (Building)   │    │    │    │
│  │  │  │  ┌──────────────┐    │    │    │    │
│  │  │  │  │  PAN (You)   │    │    │    │    │
│  │  │  │  └──────────────┘    │    │    │    │
│  │  │  └──────────────────────┘    │    │    │
│  │  └──────────────────────────────┘    │    │
│  └──────────────────────────────────────┘    │
└──────────────────────────────────────────────┘
```

> [!tip]+ 🧠 Remember
> **PAN ⊂ LAN ⊂ CAN ⊂ MAN ⊂ WAN**
> Each network type is essentially a **larger version** of the previous one.
