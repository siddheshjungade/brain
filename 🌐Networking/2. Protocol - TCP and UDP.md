# Network Protocols

> A system that allows two parties to communicate using a defined set of rules called a **protocol**.

**Examples:** TCP · UDP · HTTP · gRPC · FTP

---

## Protocol Properties

###### Data Format · Transfer Mode
| Type | Examples | Mode | Examples |
|------|----------|------|----------|
| Text | Plain Text, JSON, XML | Message | UDP, HTTP |
| Binary | Protocol Buffers, HTTP/2, HTTP/3 | Stream | TCP, WebRTC |

###### State · Routing
| Type | Examples | Routing |
|------|----------|---------|
| Stateful | TCP, gRPC, Apache Thrift | Proxy |
| Stateless | UDP, HTTP | API Gateway |

###### Flow & Congestion Control · Error Management
| Protocol | Control | Error Management |
|----------|---------|-----------------|
| TCP | Flow + Congestion control | Error codes · Retry logic |
| UDP | No control | Timeouts |

###### Addressing System · Directionality
| Addressing | Directionality |
|------------|----------------|
| DNS name | Bidirectional — TCP |
| IP address | Unidirectional — HTTP |
| MAC address | Full duplex / Half duplex |
