## 🧱 Networking Devices by OSI Layer

> Each networking device operates at a specific OSI layer. Understanding **which layer a device works at** tells you **what it can see and do** with the data passing through it.

---

## 1️⃣ Physical Layer (Layer 1)

> Deals with **raw bits** — electrical signals, light pulses, radio waves.

### 🔌 Hub

- A **dumb repeater** — receives a signal on one port and **broadcasts it to all other ports**.
- No intelligence: doesn't read MAC or IP addresses.
- Creates a **single collision domain** (all devices share bandwidth).
- **Half-duplex** — devices can't send and receive at the same time.

```
PC-A ──┐
PC-B ──┤── Hub ──┤── PC-D
PC-C ──┘         └── PC-E

💡 If PC-A sends data, ALL ports receive it (even PC-C, PC-D, PC-E).
```

### 📡 Repeater

- Takes a **weak signal**, **amplifies/regenerates** it, and sends it forward.
- Used to **extend the range** of a network over long distances.
- No filtering, no addressing — purely signal boosting.

### 🔗 Modem (Modulator-Demodulator)

- Converts **digital signals ↔ analog signals** for transmission over telephone/cable lines.
- Your home modem converts your ISP's analog signal into digital data your router can understand.

---

## 2️⃣ Data Link Layer (Layer 2)

> Deals with **frames** — uses **MAC addresses** for local delivery.

### 🔀 Switch (Layer 2 Switch)

- The backbone of any **LAN (Local Area Network)**.
- Reads **MAC addresses** from frames and forwards data **only to the correct port**.
- Maintains a **MAC Address Table** (CAM table) mapping MAC → Port.
- Creates **separate collision domains** per port (unlike a hub).
- Supports **full-duplex** communication.

```
PC-A (MAC: AA) ── Port 1 ┐
PC-B (MAC: BB) ── Port 2 ┤── Switch ──┤── Port 4 ── PC-D (MAC: DD)
PC-C (MAC: CC) ── Port 3 ┘            └── Port 5 ── PC-E (MAC: EE)

💡 If PC-A sends to MAC DD, switch forwards ONLY to Port 4.
```

| Feature         | Hub              | Switch                  |
| --------------- | ---------------- | ----------------------- |
| Operates at     | Layer 1          | Layer 2                 |
| Uses            | Broadcasting     | MAC-based forwarding    |
| Collision domain| Single (shared)  | Per port (isolated)     |
| Duplex          | Half             | Full                    |
| Intelligence    | None             | MAC address table       |

### 🌉 Bridge

- An **older device** that connects **two LAN segments**.
- Like a switch but with **fewer ports** (usually 2).
- Reads MAC addresses to decide whether to forward or drop a frame.
- Reduces collision domains by segmenting the network.

### 📶 Access Point (AP / WAP)

- Provides **wireless connectivity** to a wired network.
- Operates at Layer 2 — bridges wireless clients to the wired LAN using MAC addresses.
- Your home Wi-Fi router has a built-in AP.

---

## 3️⃣ Network Layer (Layer 3)

> Deals with **packets** — uses **IP addresses** for routing between networks.

### 🌐 Router

- The **most important Layer 3 device** — connects **different networks** together.
- Reads **destination IP address** and determines the **best path** (route) to forward the packet.
- Maintains a **Routing Table** with known networks and next hops.
- Separates **broadcast domains** (a hub/switch does not).
- Performs **NAT** (Network Address Translation) to let private IPs access the internet.

```
LAN A (192.168.1.0/24)          LAN B (10.0.0.0/24)
   PC-A ── Switch ── Router ── Switch ── PC-B
                       │
                    Internet
                       │
                   Google.com

💡 Router decides: "packet for 10.0.0.5 → send to LAN B"
                   "packet for 8.8.8.8 → send to Internet"
```

### 🔀 Layer 3 Switch (Multilayer Switch)

- A **switch with routing capabilities** built-in.
- Can forward frames using **MAC addresses** (Layer 2) AND route packets using **IP addresses** (Layer 3).
- Used in **enterprise networks** for fast inter-VLAN routing.
- Faster than a traditional router for internal traffic because routing is done in **hardware (ASIC)**.

### 🔥 Firewall (Layer 3/4)

- Filters traffic based on **IP addresses, ports, and protocols**.
- Can be a dedicated hardware device or software-based.
- Inspects packet headers and applies **rules (ACLs)** to allow or deny traffic.
- Stateful firewalls track **connection state** (SYN, ACK, etc.) at Layer 4.

```
Internet ──── Firewall ──── Internal Network
                 │
          Rules:
          ✅ Allow port 443 (HTTPS)
          ✅ Allow port 22 (SSH) from 10.0.0.0/24
          ❌ Block port 23 (Telnet)
          ❌ Block all from 203.0.113.0/24
```

---

## 4️⃣ Transport Layer (Layer 4)

> Deals with **segments/datagrams** — uses **port numbers** for process-to-process delivery.

### ⚖️ Load Balancer (Layer 4)

- Distributes incoming traffic across **multiple backend servers**.
- At Layer 4, it makes decisions based on **IP + Port** (doesn't inspect the actual content).
- Algorithms: Round Robin, Least Connections, IP Hash.

```
Client Request (TCP 443)
        │
   Load Balancer
   ┌────┼────┐
   ▼    ▼    ▼
Server1 Server2 Server3
```

### 🔒 NAT Gateway

- Translates **private IPs ↔ public IPs** using port numbers to track connections.
- Operates at Layer 3 (IP) and Layer 4 (ports) — often called Layer 3/4.
- Enables multiple devices on a LAN to share a **single public IP**.

```
Private Network                NAT Gateway              Internet
PC-A (192.168.1.2:5000) ──►  203.0.113.1:40001  ──►  google.com:443
PC-B (192.168.1.3:5001) ──►  203.0.113.1:40002  ──►  github.com:443
```

## 5️⃣–7️⃣ Session / Presentation / Application Layers (Layer 5–7)

> Deals with **data** — application protocols, encryption, session management.

### 🌐 Proxy Server (Layer 7)

- Acts as an **intermediary** between client and server.
- Inspects and can modify **HTTP requests/responses** (application layer content).
- Use cases: caching, content filtering, anonymity, logging.

### 🔄 Reverse Proxy (Layer 7)

- Sits in front of **backend servers** — clients don't know which server they're talking to.
- Examples: **Nginx, HAProxy, Traefik**.
- Handles: SSL termination, caching, load balancing, compression.

### ⚖️ Application Load Balancer (Layer 7)

- Makes routing decisions based on **HTTP content**: URL path, headers, cookies, hostname.
- Smarter than Layer 4 LB — can route `/api/*` to API servers and `/static/*` to CDN.

```
Client Request: GET /api/users
        │
   ALB (Layer 7)
        │
   Routes based on path:
   /api/*    → API Server Pool
   /static/* → Static File Server
   /ws/*     → WebSocket Server
```

### 🔥 WAF (Web Application Firewall)

- A **Layer 7 firewall** that inspects HTTP traffic for attacks.
- Protects against: **SQL injection, XSS, CSRF, bot traffic**.
- Sits in front of web applications (often paired with a reverse proxy or CDN).

### 🌍 CDN (Content Delivery Network)

- Caches and serves content from **edge servers** close to the user.
- Reduces latency by serving static assets (images, CSS, JS) from the nearest node.
- Examples: **Cloudflare, AWS CloudFront, Akamai**.

## 📊 Quick Reference: All Devices by Layer

| OSI Layer | Device | Key Feature |
|-----------|--------|-------------|
| **Layer 1** — Physical | Hub | Broadcasts to all ports |
| **Layer 1** — Physical | Repeater | Amplifies/regenerates signal |
| **Layer 1** — Physical | Modem | Digital ↔ Analog conversion |
| **Layer 2** — Data Link | Switch | MAC-based forwarding |
| **Layer 2** — Data Link | Bridge | Connects 2 LAN segments |
| **Layer 2** — Data Link | Access Point | Wireless ↔ Wired bridging |
| **Layer 3** — Network | Router | IP-based routing between networks |
| **Layer 3** — Network | L3 Switch | Switch + routing in hardware |
| **Layer 3/4** — Network/Transport | Firewall | Filters by IP, port, protocol |
| **Layer 4** — Transport | Load Balancer (L4) | Distributes by IP + port |
| **Layer 3/4** | NAT Gateway | Private ↔ Public IP translation |
| **Layer 7** — Application | Proxy Server | Inspects/modifies app traffic |
| **Layer 7** — Application | Reverse Proxy | Frontend for backend servers |
| **Layer 7** — Application | ALB (L7 LB) | Routes by HTTP content |
| **Layer 7** — Application | WAF | Blocks web attacks (SQLi, XSS) |
| **Layer 7** — Application | CDN | Caches content at edge nodes |

---

> [!tip]+ 🧠 Rule of Thumb
> **Higher the layer → Smarter the device → More expensive → Slower (but more context-aware)**
> - Layer 1 devices are **fast but dumb** (just move bits)
> - Layer 7 devices are **smart but slower** (inspect full application data)
